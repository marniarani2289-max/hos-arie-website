# Hukum Mayantara classroom
Route: /lexnusa/mayantara. Eight original units, proposed 16 meetings, four fictional cases, primary-source desk, and five-part formative rubric. Students may answer in Indonesian or English. Dates, SKS, institutional RPS and official assessment weighting are not asserted.
Students register through the shared Supabase auth service and request membership. Existing LexNusa administrators are seeded as classroom lecturers by the additive migration. Only assigned staff may admit or suspend a student; user-editable metadata never grants access.
Private text portfolios are separate from the contract-workshop cohort. Each assignment has immutable draft/submitted versions, source notes and reflection. Drafts are visible to lecturers. The database serializes writes/reviews, assigns timestamps and versions, rejects stale parents, requires source/attestation before submission, and accepts one non-self rubric review of the latest submitted version. A revision has no inherited grade. Suspended members can read history but cannot insert work.
No automatic certificate, official transcript, attendance, file upload, deadline enforcement, AI request or payment is added. AI remains unavailable.
The SQL migration was generated from the recorded remote migration version after the local CLI invocation could not run. The migration is additive and deployed through the Supabase connector.
Validation: TypeScript, scoped ESLint, and tests/lexnusa-mayantara-rls.mjs with PGlite. Production browser checks are reported separately.
