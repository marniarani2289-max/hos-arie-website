# Sumber peta orientasi Kepulauan Riau

Peta untuk halaman Pendidikan Biru (Blue Education), Dr. Hos Arie Sibarani.

Geometri daratan diproyeksikan dari data geografis, bukan ilustrasi pulau hasil generasi AI. Garis lintang/bujur menggunakan proyeksi equirectangular di dekat khatulistiwa. Titik dan label merupakan penanda lokasi representatif; tidak menunjukkan seluruh wilayah administratif kabupaten/kota. Bentuk pulau disederhanakan untuk tampilan web. Peta ini tidak menetapkan batas laut dan tidak digunakan untuk navigasi.

## Data dan atribusi

- © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), melalui [geoBoundaries](https://www.geoboundaries.org/).
- Indonesia: geoBoundaries gbOpen IDN ADM1, boundary ID `IDN-ADM1-65028918`, tahun sumber 2017; OpenStreetMap/Wambacher; pembaruan sumber 19 Januari 2023, build 12 Desember 2023. Geometri Kepulauan Riau dipilih dengan `shapeISO=ID-KR`.
- [Geometri Indonesia](https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/main/releaseData/gbOpen/IDN/ADM1/geoBoundaries-IDN-ADM1_simplified.geojson).
- [Metadata Indonesia](https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/main/releaseData/gbOpen/IDN/ADM1/geoBoundaries-IDN-ADM1-metaData.json).
- [Geometri Malaysia](https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/main/releaseData/gbOpen/MYS/ADM0/geoBoundaries-MYS-ADM0_simplified.geojson), hanya sebagai konteks geografis. Boundary ID `MYS-ADM0-87038898`, tahun sumber 2017, OpenStreetMap/Wambacher, ODbL 1.0.
- Lisensi database sumber Indonesia: [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Data sumber tersedia melalui tautan di atas. Pengolahan untuk gambar ini: pemilihan area tampilan, proyeksi, pengurangan simpul subpiksel, pewarnaan, dan label.
- Diakses 24 September 2026. Geometri ini merupakan bahan orientasi geografis dan tidak diklaim sebagai batas administrasi resmi terbaru.

Pembuatan ulang: `python scripts/build-blue-education-map.py` dari repositori website. Tidak memerlukan layanan peta pihak ketiga saat halaman dimuat.
